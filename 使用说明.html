Claude 原生助手

0.3.23 · 中文原生 Mac 应用，含菜单栏快捷入口。

怎么用

  1. 直接打开本工具检测，不需要先把 Claude 退出。
  2. 打开需要的官方功能开关。如果 Claude 正在运行，助手会先正常退出，再备份、校验并安装补丁；完成后自动重新打开 Claude。第一次安装会生成完整官方备份。
  3. 使用 Computer Use 前，在 Claude 设置 → This computer → System 确认辅助功能和屏幕录制都显示 Granted。
  4. Claude 启动、退出或电脑唤醒后，助手会自动重新检测；也可以按 ⌘R 手动刷新。
  5. 窗口只放常用操作：Computer Use 主开关、五个原生配置开关、打开 Claude 和重新检测。更新补丁只在真的可更新时出现。
  6. 低频操作放在菜单栏图标里：显示主窗口、重新检测、打开 Claude、更新解锁补丁、为官方更新做准备、系统授权说明、使用说明、关于和退出。

官方更新：先恢复，再更新

补丁版使用的是临时签名，官方更新器会拒绝这种签名，表现为一直卡在下载或提示签名校验失败。

正确顺序：在菜单栏图标里点 “为官方更新做准备”（快捷键 ⌘P；Claude 正在运行时会先自动退出）→ 工具恢复完整官方签名和官方文件 → 打开 Claude 安装官方更新 → 更新完成后回到本工具点 “重新检测”。

恢复不会删除当前官方备份、配置或会话。更新后如果显示“尚未适配”，等待维护者发布对应版本；工具只会在检测到已适配版本时才修改 Claude，不会把旧补丁套到新版本。

官方更新到尚未适配的版本后，“打开 Claude”仍然可用；工具只会在检测到已适配版本时才修改 Claude。备份会绑定到同版本的具体构建，避免同版本不同构建的备份互相覆盖。

提示建议：按 Tab 采纳

Claude 回复结束后，输入框里可能先出现一段浅色的“建议下一句”。它不是已经填好的文字，点击它或直接按回车都不会发送。

正确操作：先按 Tab 采纳建议，文字进入输入框后，再按 回车 发送。也可以先按 Tab，再修改内容。

如果不想看到建议，可以在 Claude 设置中关闭 “Prompt suggestions”（提示建议）。0.3.6 补丁会让这个官方设置项在第三方 API 模式下可见。

功能开关

  • Chat 与高级文件分析：Chat 使用标准工作台，启用官方高级文件分析。
  • 官方内置浏览器：启用 Claude 官方内置浏览器，不是 Dia 或 Chrome。
  • 官方定时任务：允许官方定时任务；是否执行仍由 Claude 决定。
  • Cowork 自动审批选项：显示官方自动审批选项；动作审查和权限流程保留。
  • 插件里的桌面扩展：允许插件打包的桌面扩展（.mcpb）加载；官方签名检查仍然生效。
  • MCP 工具按需加载：MCP 工具改为按需加载，不再全部塞进上下文；网关不支持时走官方旧路径。
  • WebFetch 免域名预检：跳过 Code 里 WebFetch 对 api.anthropic.com 的域名预检；抓取仍走官方 WebFetch。
  • Code 原生自动整理可用性：只解除 Code 自动整理的可用性限制；当前 CLI 版本由后端检测，用户开关保持。

这些开关只改 Claude 已有的官方配置，不提供替代执行器、云服务或账号系统。

验证新开关（可选）

  • 插件里的桌面扩展：安装一个带 .mcpb 的插件，确认扩展被加载。
  • MCP 工具按需加载：在 Code 会话里连接多个 MCP 服务器，确认工具按需出现。
  • WebFetch 免域名预检：在 Code 会话里让 Claude 抓取一个网页，确认不再报域名预检失败。

这三项只有实际用过才算验收通过；没有用之前，工具不会把它们标成已验证。

备份与恢复

状态和当前官方备份保存在 ~/Library/Application Support/Claude 原生助手/。工具只保留最新补丁和当前官方备份，更新成功后会清理旧补丁、旧备份和旧报告；请不要手动删除该目录。

更新本助手本身不会重新签名或修改 Claude：替换 Applications 里的应用即可，恢复记录仍在原处。只有安装/更新 Claude 补丁时才会重签 Claude。

每次检测都会核验当前补丁对应的官方备份。备份版本错误、文件损坏或路径被重定向时，窗口和菜单栏会提示备份异常，并停用恢复和补丁更新；已经通过文件校验的 Claude 仍可打开。请先找回原备份，再重新检测。

关闭主开关会恢复完整官方原版。工具不会清理 Claude 的会话或缓存。

支持范围与边界

当前补丁动作只验证 Apple Silicon / macOS 27.0.1。Desktop 适配 2.31226.1、2.37337.1、2.42304.0、2.42304.2 与 3.1623.0；遇到未登记的新版本会按官方签名和功能表结构自动识别。Code 自动整理适配 CLI 2.1.295、2.1.299、2.1.304。

保留官方逐应用授权、系统权限、截图过滤、拒绝、中断和动作审查。第三方模型能否完成某个具体操作，取决于模型本身，不等于解锁失败。蓝色代码水波尚未找到原生开启入口，本工具不制作替代动画。

首次发布使用临时签名，没有 Apple Developer ID 签名或公证；macOS 可能阻止首次打开。请自行核对源码和校验和，通过系统正常界面决定是否允许，不需要关闭 Gatekeeper 或 SIP。

独立开源项目，与 Anthropic 无隶属关系。源码与更多说明见随发布提供的 README。
