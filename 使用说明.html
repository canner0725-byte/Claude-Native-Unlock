Claude 原生助手

0.3.1 · 中文原生 Mac 应用，含菜单栏快捷入口。

使用

  1. 先正常退出 Claude，再检测和切换所需补丁。
  2. 完成备份和校验后打开 Claude。使用 Computer Use 前，在 Claude 设置 → System 确认辅助功能和屏幕录制均显示 Granted。
  3. 关闭主窗口后，菜单栏的开锁图标仍可打开主窗口、检测状态、打开 Claude 或退出。

备份与官方更新

备份保存在 ~/Library/Application Support/Claude Native Unlock/。通过“打开备份目录”查看，请保留这些文件。

Claude 官方更新前先关闭桌面补丁，恢复完整官方签名；更新后重新检查适配。未知版本和指纹不会被自动修改。签名改变可能需要在系统正常界面重新绑定原有权限。

支持与边界

当前补丁动作仅验证 Apple Silicon / macOS 27.0.1；Desktop 2.31226.1、2.37337.1 与固定 CLI 2.1.295。应用不需要 Python 或 Xcode。第三方 API 沿用 Claude 已有配置。
