# Claude 原生助手

[下载安装包](https://github.com/canner0725-byte/Claude-Native-Unlock/releases/latest) · [源码仓库](https://github.com/canner0725-byte/Claude-Native-Unlock)

中文原生 macOS 应用，为 Claude Desktop 第三方 API（3P）部署管理已适配的原生功能可用性。Swift / AppKit 界面，带菜单栏图标；运行所需 Python 已内置，无需安装 Python、Xcode 或打开终端。

这是独立社区项目，与 Anthropic 无隶属关系。仅分发我们编写的工具；不分发 Claude 安装包、原生模块、第三方 API 密钥、会话数据或个人备份。本工具界面为中文，不代表将 Claude 本体全部汉化。

## 功能

- 补丁 revision 14 适配官方 Claude Desktop **3.6556.2**（主 chunk `.vite/build/index.chunk-jPKPzV-P.js`），补回该版官方删掉的 5 个渲染进程可用性默认值：会话状态分组、每文件夹工作树、PR 自动修复、PR 面板、Code 权限请求分类。渲染进程表遇到官方已有的同名条件一律拒绝覆盖；11 个门的解析已端到端验证，入口的实际功能行为尚未在运行时验收。
- 界面是单页设置列，没有侧栏：顶部一行是助手身份、实时状态和版本，右上角只有一个刷新图标（加载时它自己旋转）；下面依次是总开关、它包含的功能、维护、系统授权和关于。配色对齐 Claude 桌面端（近黑面板、蓝色开关、灰色按钮），浅色/深色自适应。
- 「维护 → 检查更新」会提示 Claude 官方有没有新版：只读查询官方更新渠道（latest 渠道，比 stable 更早看到新版本），只带本机版本、系统版本和固定探针标识，不登录、不下载、不碰用户配置；结果缓存 6 小时，旁边「立即检查」可随时强制重查。有新版时整句用强调色并注明本工具是否已适配，**点这行字就直接进入准备更新**（恢复完整官方签名，供官方更新器校验）；没查到或联网失败时如实说明，不会显示成「已是最新」。
- 「维护 → 官方备份」最右边有「恢复官方原版」：用当前已校验的官方备份把 Claude 恢复成官方原版，和关闭总开关走同一条路径，备份、配置和会话都保留；安装中断时也能一键恢复。
- Computer Use、新版 Code 工作台、侧问题子会话与后续子任务、状态分组（`Group by → Status`）与每文件夹工作树的固定版本可用性补丁。
- Code 原生自动记忆整理的可用性补丁；保留用户开关和官方触发条件（24 小时 / 5 个会话 / 锁与权限规则全部原样）。2.1.308 上已实测走完 `firing → completed` 并改写合成记忆；同一份配置下官方未打补丁副本连 runner 都进不去。
- 官方 Chat/文件分析、内置浏览器、Cowork 自动审批选项、插件里的桌面扩展（.mcpb）、MCP 工具按需加载和 WebFetch 免域名预检的配置管理；只收官方第三方部署下默认关闭的项，官方默认就开启的功能不重复出现在界面里。每一项都按当前 Claude 版本核对，官方删掉的设置会被跳过并在界面上点名。
- 「扩展与插件」一组会显示已安装插件数与检测到的 `.mcpb` 数量：扩展只能随插件安装，开关打开不等于扩展已经加载。
- 原版指纹、签名、版本检查；当前官方备份、恢复和补丁更新。每次检测同时核验对应版本的官方备份，异常时明确提示。
- 只保留最新补丁和当前官方备份；更新成功后自动清理旧补丁、旧备份和旧报告。
- Claude 运行时也能直接切换总开关：确认后助手会正常退出 Claude，完成修改再自动打开。
- 这个助手只有全开和全关两种状态，所以只有一个总开关：一次完成补丁、6 个原生配置项和 Code 自动整理，并逐项回报完成、跳过或失败。关闭主窗口不会退出菜单栏。

只调整目标可用性条件，不提供替代 Computer Use 执行器或云服务。不改变逐应用授权、系统权限、拒绝、中断、截图过滤或动作审查。不会自动登录或收集 API 密钥。

## 下载与安装

在 GitHub Releases 下载 Apple Silicon 的 `.dmg`，打开后将 Claude 原生助手拖入 Applications，也可使用 `.zip`。双击应用即可使用。首次发布使用临时签名，**没有 Apple Developer ID 签名或公证**；macOS 可能阻止首次打开。请自行核对源码和校验和，通过系统正常界面决定是否允许，不需要关闭 Gatekeeper 或 SIP。

状态及备份位于 `~/Library/Application Support/Claude 原生助手/`。移动应用、删除源码目录、更新本工具均不应删除此目录；恢复 Claude 原版需要其中的当前官方备份。工具只保留最新补丁和当前官方备份，更新成功后会清理旧补丁、旧备份和旧报告。更新本助手本身只需替换 Applications 里的应用，不会重新签名或修改 Claude；只有安装/更新 Claude 补丁时才会重签 Claude。

### 版本保留策略

- 发布目录只保留当前版本的 `.app`、`.dmg`、`.zip` 和 `SHA256SUMS.txt`；构建成功后 `scripts/build.py` 会删除旧安装包和 `build/` 中间产物。
- 补丁状态只保留当前官方备份；安装或更新成功后自动删除旧补丁、旧备份和旧报告。
- `tests/` 中的公开合成测试保留在源码仓库，用于后续版本适配；测试输出、测试应用副本和旧构建不进入发布目录。

### 使用顺序

1. 打开本工具检测，不需要先退出 Claude。
2. 选择所需功能。如果 Claude 正在运行，助手会先正常退出，备份和校验完成后自动重新打开 Claude。
3. 使用 Computer Use 前，在 Claude 设置的 System 页确认 Accessibility、Screen recording 均为 Granted；签名变化可能要求重新绑定同一应用并重启。
4. Claude 官方更新前，点“检查更新”下面那行新版提示（或菜单里的“为官方更新做准备”）恢复完整官方签名（助手会先退出 Claude）；更新后点“重新检测”。不能直接将旧补丁套到新版本。
5. 想直接回到官方原版时，点「官方备份」那一栏最右边的“恢复官方原版”；和关闭总开关效果相同，备份、配置和会话都会保留。

### 签名身份等于 Claude 的系统授权

固定签名身份让补丁版 Claude 在更新后不用重新授权，代价是：**谁拿到这把身份的私钥，谁就能签出被系统当成同一个 Claude 的程序，直接继承辅助功能和屏幕录制授权。**

私钥存在本机的独立钥匙串文件里，密码以 0600 权限放在同一目录。已实测：登录钥匙串的访问控制对同用户进程不提供隔离，数据保护钥匙串需要的 entitlement 自签证书拿不到，所以目前**没有更强的保护手段**。因此：

- 不要导出、复制或备份这把身份，也不要把它同步到别的机器；
- 不要在这台机器上运行来源不明的同用户程序——它和你有相同的访问权限；
- 公开分发时改用 Developer ID 签名并公证，不要用这把本地身份。

### 提示建议：按 Tab 采纳

Claude 回复结束后，输入框里可能先出现一段浅色的“建议下一句”。它不是已经填好的文字：点击它或直接按回车都不会发送。先按 **Tab** 采纳，文字进入输入框后，再按回车发送。0.3.6 补丁会让官方 “Prompt suggestions” 设置项在第三方 API 模式下可见，可以按需关闭。

## 从源码构建

构建需要 Apple Silicon Mac、Xcode Command Line Tools 和 Python 3.12。运行打包后的应用无需这些开发依赖。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-build.txt
.venv/bin/python scripts/build.py
```

产物在 `dist/`，包括原生 `.app`、DMG、ZIP 和 `SHA256SUMS.txt`。图标由仓库中的 Swift 矢量代码生成，不使用 Claude 官方图标。内置补丁组件使用 PyInstaller 打包，参见[官方说明](https://pyinstaller.org/en/stable/usage.html)。

```sh
.venv/bin/python -m unittest discover -s tests -v
```

公开测试使用临时合成数据，不需要 Claude 安装包、密钥或登录。真实安装验收必须在明确版本的隔离应用副本进行，禁止对工作文档做测试。

### 版本适配时先跑功能表审计

```sh
.venv/bin/python scripts/feature_audit.py --rows
```

只读已安装 Claude 里的官方 JS 源码，不启动也不控制应用。它把主进程预载表拆开，标出哪些条目是**写死的字面量**（不构成证据）、哪些走真实谓词，以及每个谓词查的是哪个功能键、该键在官方强制表里的取值。官方升级后用它判断封印形状有没有变，比逐个读混淆代码快得多。

一个容易踩的坑：主进程下发给渲染进程的 `--desktop-features` 启动参数**不是**判定结果，它出自同步预载表，多数条目是常量。判断某个功能有没有被封印，只能看运行时谓词。

早期项目目录版本用户可以在确认当前安装与原版备份匹配后运行：

```sh
.venv/bin/python scripts/migrate_state.py /path/to/legacy-project
```

迁移只复制并核验恢复记录及必要备份，保留源目录，不复制账号、密钥和聊天数据。迁移后使用 Applications 中的新助手，不再交替运行旧项目目录工具。不覆盖已经存在的目标记录，失败现场保留供诊断。
